# 🇳🇿 New Zealand Population Analysis

## Overview
Drawing on my background in financial data analysis and compliance 
(ANZ Bank NZ, Hyundai Capital NZ), this project explores New Zealand 
public demographic data to identify regional population trends and 
patterns.
## Skills Demonstrated
- Data wrangling with Python
- Statistical analysis of demographic trends
- Dashboard design with Power BI
- Translating raw public data into actionable insights
## Business Questions
- Which regions are experiencing the fastest population growth?
- How does population distribution shift across age groups by region?
- What demographic patterns are emerging post-COVID?

## Data Source
- Stats NZ (stats.govt.nz) — publicly available, free

## Tools Used
- **Python** (pandas, matplotlib, seaborn) — data cleaning & analysis
- **Power BI** — interactive dashboard & visualization
- **Jupyter Notebook** — documented analysis workflow## Key Findings
- **Auckland's dominance is growing**: Auckland's share of NZ's total 
  population rose from 31% (2000) to 36% (2023), confirming increasing 
  urbanisation pressure on infrastructure and housing.
  
- **30% population growth over 23 years**: NZ total population grew 
  from 3.9M to 5.1M, with growth accelerating post-2015 driven by 
  net migration.

- **COVID-19 shock clearly visible in data**: 2021 recorded the only 
  negative growth year due to border closures, followed by a sharp 
  rebound of 4.1% in 2022 as migration resumed — the highest rate 
  in the dataset.
